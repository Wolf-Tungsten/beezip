
**IP 核名称:** `block_fifo`

**版本:** v1.0

**1. 概述**

`block_fifo` 模块是一个同步 FIFO (First-In, First-Out) 缓冲器，**专为高吞吐率的块数据 (burst data) 传输应用而设计**。 它采用 **Valid-Ready 握手协议** 进行数据传输控制，并提供 **背压 (backpressure)** 机制，以适应上下游数据速率不匹配的情况。  此外，`block_fifo` 模块还支持 **同步 Flush 功能**，用于清空 FIFO 内部数据。

**核心特性:**

*   **块数据 (Burst Data) 传输:**  优化用于传输固定大小或可变大小的数据块，提高数据吞吐率。
*   **Valid-Ready 握手协议:**  标准的同步数据传输接口，易于集成到各种数字系统中。
*   **背压 (Backpressure) 机制:**  通过 `i_ready` 和 `o_ready` 信号实现背压控制，防止数据溢出或欠载。
*   **可配置参数:**
    *   数据位宽 (`W`)
    *   FIFO 深度 (`BUF_DEPTH`)
    *   块大小 (`N`)
*   **可变长度输入块:**  支持通过 `i_count` 信号指示可变长度的输入数据块。
*   **同步 Flush 功能:**  通过 `i_flush` 信号同步清空 FIFO 内部数据。
*   **Word 级别输出选通 (`o_strb`):**  指示输出数据 `o_data` 中每个 Word 的有效性。
*   **Flush 完成指示 (`o_last`):**  指示 Flush 操作完成。
*   **FIFO 计数 (`fifo_count`):**  指示 FIFO 当前存储的数据字数量。

**2. 接口信号**

| 信号名称       | 方向  | 位宽        | 类型      | 描述                                                                                                                               |
| ------------ | ----- | ----------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `clk`        | 输入  | 1 bit       | logic    | 时钟信号，所有操作均在时钟上升沿触发。                                                                                                   |
| `rst_n`      | 输入  | 1 bit       | logic    | 复位信号，低电平有效，异步复位，同步释放。                                                                                               |
| **输入接口**   |       |             |          |                                                                                                                                  |
| `i_valid`    | 输入  | 1 bit       | logic    | 输入 Valid 信号，高电平表示输入数据 `i_data` 有效。                                                                                             |
| `i_ready`    | 输出  | 1 bit       | logic    | 输入 Ready 信号，高电平表示 FIFO 模块已准备好接收输入数据。                                                                                         |
| `i_data`     | 输入  | `N*W` bits   | logic    | 输入数据总线，一次传输 `N` 个 `W` 位宽的数据字。                                                                                             |
| `i_count`    | 输入  | `PTR_WIDTH` bits | logic    | 输入数据块有效字计数。指示当前 `i_data` 中有效的 Word 数量，范围为 `1` 到 `N`。当需要传输固定大小块时，`i_count` 始终为 `N`。                                              |
| `i_flush`    | 输入  | 1 bit       | logic    | 同步 Flush 信号，高电平有效。当 `i_flush` 为高电平时，模块开始 Flush 操作，清空 FIFO 中的数据，并停止接收新的输入数据。                                                            |
| **输出接口**   |       |             |          |                                                                                                                                  |
| `o_valid`    | 输出  | 1 bit       | logic    | 输出 Valid 信号，高电平表示输出数据 `o_data` 有效。                                                                                             |
| `o_ready`    | 输入  | 1 bit       | logic    | 输出 Ready 信号，高电平表示下游模块已准备好接收输出数据。                                                                                         |
| `o_data`     | 输出  | `N*W` bits   | logic    | 输出数据总线，一次输出最多 `N` 个 `W` 位宽的数据字。                                                                                             |
| `o_strb`     | 输出  | `N` bits     | logic    | 输出选通信号，`o_strb[i]` 为高电平表示 `o_data` 中第 `i` 个 `W` 位宽的数据字有效。在 Flush 期间，`o_strb` 可以指示剩余的有效数据。                                              |
| `o_last`     | 输出  | 1 bit       | logic    | Flush 完成指示信号。在 Flush 操作的最后一次数据输出时，`o_last` 信号拉高一个时钟周期，指示 Flush 操作完成，FIFO 已被清空。                                                     |
| `fifo_count` | 输出  | `PTR_WIDTH` bits | logic    | FIFO 计数器，指示当前 FIFO 中存储的数据字数量 (以 `W` 位宽为单位)。                                                                                   |

**3. 参数说明**

| 参数名称      | 位宽   | 类型     | 默认值 | 描述                                                                                                                               |
| ----------- | ---- | -------- | ---- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `W`         | -    | integer  | 32   | 数据字位宽 (Data Width)，单位为 bit。                                                                                                |
| `BUF_DEPTH` | -    | integer  | 64   | FIFO 深度 (Buffer Depth)，以 `W` 位宽的数据字为单位。 **建议设置为 2 的幂次方，且至少为 `2*N`**，以获得更好的性能。                                                              |
| `N`         | -    | integer  | 32   | 块大小 (Block Size)，定义每次 burst 传输的数据字数量。输入输出接口 `i_data` 和 `o_data` 的位宽均为 `N*W`。                                                               |
| `PTR_WIDTH` | -    | integer  | -    | 指针位宽 (Pointer Width)，用于寻址 FIFO 内部存储器。  **由 `BUF_DEPTH` 自动计算得出，无需用户指定。  计算公式为 `PTR_WIDTH = $clog2(BUF_DEPTH)`**。 |

**4. 功能描述**

`block_fifo` 模块实现了一个基于寄存器阵列的同步 FIFO。

*   **数据写入:** 当 `i_valid` 和 `i_ready` 信号同时为高电平时，模块接收来自 `i_data` 的数据，并将最多 `i_count` 个 Word 写入 FIFO 内部存储器。写入地址由内部写指针 `i_ptr_reg` 管理。当 FIFO 已满时，`i_ready` 信号将被拉低，向上游模块施加背压。
*   **数据读取:** 当 `o_valid` 和 `o_ready` 信号同时为高电平时，模块从 FIFO 内部存储器读取数据，并通过 `o_data` 输出最多 `N` 个 Word。读取地址由内部读指针 `o_ptr_reg` 管理。当 FIFO 为空时，`o_valid` 信号将被拉低。
*   **Valid-Ready 握手:**  输入和输出接口均采用 Valid-Ready 握手协议。数据传输只有在 Valid 和 Ready 信号同时为高电平时才会发生。
*   **背压机制:**  当 FIFO 接近满 (写入侧) 或空 (读取侧) 时，模块会通过拉低 `i_ready` 或 `o_valid` 信号来施加背压，控制数据流速。
*   **Flush 操作:** 当 `i_flush` 信号为高电平时，模块进入 Flush 状态。
    *   **停止接收新数据:**  Flush 期间，模块忽略 `i_valid` 信号，不再接收新的输入数据。
    *   **输出剩余数据:**  模块继续将 FIFO 中剩余的数据输出，直到 FIFO 为空。
    *   **`o_last` 信号指示完成:**  在 Flush 操作的最后一次数据输出时，`o_last` 信号拉高一个时钟周期，指示 Flush 操作完成。
    *   **优先级高于输入:**  `i_flush` 信号的优先级高于输入数据请求。当 `i_flush` 和 `i_valid` 同时为高电平时，优先执行 Flush 操作。
*   **FIFO 计数器:**  `fifo_count` 信号实时指示 FIFO 中当前存储的数据字数量，可用于监控 FIFO 状态。

**5.  时序说明**

`block_fifo` 模块为同步设计，所有操作均在时钟信号 `clk` 的上升沿触发。

*   **复位:**  `rst_n` 为异步复位信号，低电平有效。建议在系统上电或需要初始化时，将 `rst_n` 拉低至少一个时钟周期。 复位释放为同步释放。
*   **延迟:**  数据从输入到输出的延迟主要取决于 FIFO 的深度和读写操作的时序。  在正常工作情况下，延迟较小。

**6.  资源占用**

`block_fifo` 模块的资源占用主要包括：

*   **寄存器:**  用于存储读写指针、计数器和控制逻辑。
*   **存储器 (寄存器阵列):**  用于存储 FIFO 数据，大小为 `BUF_DEPTH * W` bits。

实际资源占用会根据参数 `W`、`BUF_DEPTH` 和 `N` 的具体配置而有所不同。

**7.  使用注意事项**

*   **时钟和复位:**  确保 `clk` 和 `rst_n` 信号连接正确且稳定。
*   **参数配置:**  根据实际应用需求合理配置参数 `W`、`BUF_DEPTH` 和 `N`。  **`BUF_DEPTH` 建议设置为 `2*N` 或更大**，以获得较好的 burst 传输性能。
*   **Valid-Ready 握手:**  上下游模块必须正确实现 Valid-Ready 握手协议，才能保证数据传输的正确性。
*   **Flush 操作:**  在需要清空 FIFO 数据时，可以使用 `i_flush` 信号。  注意 `i_flush` 信号为同步信号，且优先级高于数据输入。 下游模块应使用 `o_last` 信号来判断 Flush 操作是否完成。
*   **数据位宽匹配:**  确保上下游模块的数据位宽与 `block_fifo` 模块的 `W` 参数一致。
